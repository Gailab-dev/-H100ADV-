1. SSL 키 자체 서명 재발급
===================================================

[Windows 로컬 발급 - PowerShell 한 줄]

mkdir C:\Users\<계정>\workspace\ssl-keys\module_c
cd C:\Users\<계정>\workspace\ssl-keys\module_c

openssl req -x509 -nodes -days 365 -subj "/CN=<웹서버 IP>" -newkey rsa:2048 -keyout server.key.pem -out server.cert.pem


[발급 확인]

openssl x509 -in server.cert.pem -noout -subject -dates


[서버 배포]

scp C:\Users\<계정>\workspace\ssl-keys\module_c\server.key.pem C:\Users\<계정>\workspace\ssl-keys\module_c\server.cert.pem <계정>@<웹서버 IP>:/home/<계정>/h100_module_c/ssl/


[서버 권한]

chmod 600 /home/<계정>/h100_module_c/ssl/server.key.pem
chmod 644 /home/<계정>/h100_module_c/ssl/server.cert.pem

3. HMAC 64byte 난수 생성·설정
===================================================

[생성 방법 - Linux]

방법 1 - openssl
openssl rand -hex 32

방법 2 - /dev/urandom
head -c 32 /dev/urandom | xxd -p -c 64

방법 3 - python3
python3 -c "import secrets; print(secrets.token_hex(32))"


[출력 예시]
a3f2e1b8c94d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f


[적용]
1. 위 값을 .env 의 DEVICE_HMAC_KEY 에 반영
2. module_d 의 .env 에도 동일한 값 반영 (필수)

5. systemctl 등록
===================================================

[서비스 파일 경로]
/etc/systemd/system/h100_module_c.service


[서비스 파일 내용]

[Unit]
Description=H100 Module C - Web Server
After=network.target mysql.service
Wants=network-online.target

[Service]
Type=simple
User=<계정>
Group=<그룹>
WorkingDirectory=/home/<계정>/h100_module_c
ExecStart=/home/<계정>/h100_module_c/h100_module_c
Restart=on-failure
RestartSec=10
StandardOutput=append:/home/<계정>/h100_module_c/logs/systemd.log
StandardError=append:/home/<계정>/h100_module_c/logs/systemd_error.log
Environment="PATH=/usr/local/go/bin:/usr/bin:/bin"

[Install]
WantedBy=multi-user.target


[로그 폴더 신설]

mkdir -p /home/<계정>/h100_module_c/logs
chown <계정>:<그룹> /home/<계정>/h100_module_c/logs


[등록·시작]

sudo systemctl daemon-reload
sudo systemctl enable h100_module_c
sudo systemctl start h100_module_c

===================================================
9. Windows CRLF 오류 해결
===================================================

[오류 메시지]
-bash: ./start.sh: /bin/bash^M: 잘못된 인터프리터


[해결]

방법 1 - dos2unix
sudo apt-get install dos2unix
dos2unix start.sh stop.sh
chmod +x start.sh stop.sh

방법 2 - sed
sed -i 's/\r$//' start.sh stop.sh
chmod +x start.sh stop.sh


[확인]

file start.sh
정상: ASCII text
비정상: ASCII text, with CRLF line terminators
